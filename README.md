# RiskUA Bot

**RiskUA Bot** — Telegram-бот для швидкої перевірки українських компаній за ЄДРПОУ перед оплатою, підписанням договору або початком співпраці.

Основна ідея проєкту — допомогти ФОПам, малому бізнесу, волонтерам, менеджерам із закупівель та іншим користувачам швидко оцінити базові ризики контрагента без ручного пошуку інформації в різних відкритих джерелах.

---

## Основна проблема

Перед оплатою рахунку, укладанням договору або співпрацею з новим постачальником часто потрібно швидко зрозуміти:

* чи існує компанія;
* чи має вона активний статус;
* як давно вона зареєстрована;
* чи відповідає діяльність компанії заявленій сфері;
* чи є базові ознаки ризику;
* чи варто робити передоплату;
* які дані потрібно додатково перевірити.

Зазвичай користувач має самостійно відкривати кілька сайтів, шукати інформацію за ЄДРПОУ, порівнювати дані та робити висновки вручну. RiskUA Bot має спростити цей процес.

---

## Як працює бот

Користувач відкриває Telegram-бота та вводить ЄДРПОУ компанії.

Бот виконує перевірку та повертає коротку картку контрагента:

1. Користувач надсилає ЄДРПОУ.
2. Backend отримує запит від Telegram-бота.
3. Система шукає базові дані про компанію.
4. Модуль ризиків аналізує отримані дані за простими правилами.
5. Бот повертає користувачу результат перевірки:

   * базові дані компанії;
   * статус;
   * дату реєстрації;
   * основний КВЕД;
   * рівень ризику;
   * список можливих ризикових ознак;
   * коротку рекомендацію.

У майбутніх версіях бот також зможе формувати PDF-звіт та пояснювати результати перевірки за допомогою AI.

---

## Приклад сценарію використання

Користувач отримав рахунок від нового постачальника та хоче перевірити компанію перед оплатою.

Він надсилає боту ЄДРПОУ:

```text
12345678
```

Бот повертає відповідь:

```text
Компанія: ТОВ "Приклад"
ЄДРПОУ: 12345678
Статус: активна
Дата реєстрації: 15.01.2024
Основний КВЕД: 46.90

Рівень ризику: середній

Ознаки:
- компанія зареєстрована відносно недавно;
- критичних ознак у базовій перевірці не знайдено.

Рекомендація:
Перед передоплатою перевірте договір, реквізити, документи та підтвердження наявності товару або послуги.
```

## Логіка оцінки ризику

RiskUA Bot не робить юридичних висновків і не визначає, чи є компанія шахрайською. Сервіс лише показує базові ознаки, які можуть потребувати додаткової уваги.

Приклади ризик-правил:

### Високий ризик

* компанію не знайдено;
* компанія має неактивний або припинений статус;
* відсутні важливі базові дані;
* виявлені критичні негативні ознаки у доступних джерелах.

### Середній ризик

* компанія зареєстрована нещодавно;
* основний КВЕД не повністю відповідає заявленій діяльності;
* недостатньо публічної інформації;
* дані потребують додаткової ручної перевірки.

### Низький ризик

* компанія активна;
* компанія працює тривалий час;
* базові дані виглядають узгоджено;
* критичних ризикових ознак не знайдено.

## Важливе застереження

RiskUA Bot не є юридичним, фінансовим або офіційним державним висновком.

Результат перевірки має інформаційний характер і базується на доступних даних на момент запиту. Остаточне рішення щодо співпраці, оплати або укладання договору користувач приймає самостійно.

Перед передоплатою або підписанням договору рекомендується додатково перевірити:

* реквізити компанії;
* договір;
* рахунок;
* документи;
* відгуки;
* фактичну наявність товару або послуги;
* умови повернення коштів;
* репутацію контрагента.

## Архітектура проєкту

Бот побудований так, щоб Telegram був лише інтерфейсом, а основна логіка знаходилась у backend.

Загальна схема:

```text
Telegram Bot
    ↓
FastAPI Backend
    ↓
Company Lookup Service
    ↓
Risk Engine
    ↓
AI Report Service
    ↓
PDF Generator
    ↓
Telegram Response
```

## Локальний запуск

### 1. Клонувати репозиторій

```bash
git clone https://github.com/your-username/riskua-bot.git
cd riskua-bot
```

### 2. Створити віртуальне середовище

```bash
python -m venv .venv
```

### 3. Активувати середовище

Для Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Для Linux/macOS:

```bash
source .venv/bin/activate
```

### 4. Встановити залежності

```bash
pip install -r requirements.txt
```

### 5. Створити файл `.env`

```env
BOT_TOKEN=your_telegram_bot_token
APP_ENV=local
```

### 6. Запустити Telegram-бота

```bash
python -m app.bot
```

### 7. Запустити FastAPI backend

```bash
uvicorn app.main:app --reload
```

Документація API буде доступна за адресою:

```text
http://127.0.0.1:8000/docs
```
